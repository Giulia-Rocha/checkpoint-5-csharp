# Prints da aplicação

As imagens da entrega devem ser capturadas manualmente após preparar o banco e executar a aplicação.

Capturas recomendadas:

1. Produto preenchido no formulário e exibido na listagem após a inserção.
2. Busca por ID concluída e produto carregado para atualização.
3. Exclusão concluída, com mensagem de sucesso ou lista atualizada.

Salve os arquivos nesta pasta como `01-insercao-listagem.png`, `02-busca-atualizacao.png` e `03-exclusao.png`.
